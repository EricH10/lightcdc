# Security Policy

## Supported Versions

Security fixes are applied to the latest released minor version. The project is
currently pre-1.0, so upgrade to the latest patch before reporting an issue.

## Reporting

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory reporting for `EricH10/lightcdc` and include reproduction
steps, affected versions, and whether event data or credentials may be exposed.

Do not attach production row payloads, PostgreSQL passwords, bearer tokens,
private keys, or unredacted configuration. Maintainers will coordinate a fix,
advisory, release, and disclosure timeline through the private report.
